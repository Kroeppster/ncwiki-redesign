# NCWiki Redesign - Modern Website for Swiss Medical Exam Preparation\n\nA beautiful, modern redesign of NCWiki with improved UI/UX, better content organization, and free hosting on GitHub Pages.\n\n## 🚀 Quick Start\n\n### Prerequisites\n- Node.js 18+ installed\n- npm installed\n\n### Installation\n\n```bash\n# Clone the repository\ngit clone https://github.com/Kroeppster/ncwiki-redesign.git\ncd ncwiki-redesign\n\n# Install dependencies\nnpm install\n\n# Run development server\nnpm run dev\n```\n\nOpen [http://localhost:3000](http://localhost:3000) in your browser.\n\n## 📄 Pages\n\n- **Home** - Hero section with quick overview\n- **Übungsserien** - Practice materials and exercises\n- **Untertests** - Information about EMS subtests\n- **Neuigkeiten** - News and announcements\n- **Über Uns** - About NCWiki and values\n- **Kontakt** - Contact form\n\n## 🎨 Features\n\n✅ **Modern Design** - Clean, professional UI  \n✅ **Dark Mode** - Built-in light/dark theme toggle  \n✅ **Responsive** - Mobile-first design  \n✅ **Fast** - Static site generation  \n✅ **SEO Optimized** - Proper metadata  \n✅ **German Language** - Full German content  \n\n## 🛠️ Technology Stack\n\n- **Next.js 15** - React framework with SSG\n- **TypeScript** - Type-safe code\n- **Tailwind CSS** - Utility-first styling\n- **React Icons** - Icon library\n\n## 🚀 Build & Deploy\n\n### Build for Production\n\n```bash\nnpm run build\n```\n\nThis creates an optimized static site in the `out/` folder.\n\n### Deploy to GitHub Pages\n\nThe repository includes a GitHub Actions workflow that automatically deploys on every push to `main`.\n\n**To enable GitHub Pages:**\n\n1. Go to your repo Settings → Pages\n2. Select **Deploy from a branch**\n3. Choose branch: **main**\n4. Select folder: **/out**\n5. Save\n\nYour site will be live at: `https://Kroeppster.github.io/ncwiki-redesign/`\n\n## 📝 Customization\n\n### Change Content\n\nEdit page content in `/app` directory:\n- Homepage: `app/page.tsx`\n- Exercise page: `app/uebungen/page.tsx`\n- And more...\n\n### Customize Styling\n\nEdit Tailwind config:\n```typescript\n// tailwind.config.ts\n```\n\n### Update Navigation\n\nEdit the Header component:\n```typescript\n// components/Header.tsx\n```\n\n## 📚 Project Structure\n\n```\n.\n├── app/                    # Next.js app pages\n│   ├── layout.tsx         # Root layout\n│   ├── page.tsx           # Home page\n│   ├── globals.css        # Global styles\n│   └── [page]/page.tsx    # Dynamic pages\n├── components/             # Reusable components\n│   ├── Header.tsx\n│   ├── Footer.tsx\n│   ├── Card.tsx\n│   └── ...\n├── public/                # Static assets\n├── next.config.mjs        # Next.js configuration\n├── tailwind.config.ts     # Tailwind configuration\n└── package.json           # Dependencies\n```\n\n## 🤝 Contributing\n\nNCWiki is a community-driven project.
